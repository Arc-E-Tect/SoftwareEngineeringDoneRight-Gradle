= Tracker Lens — Scaffolded Lens Pack Example
:toc: left

== Description

The real, unedited output of `bootstrapTrackerLensProject`, checked in under `generated/`: a
lens-pack project and a sample project already wired to consume it, matching the plugin's own
`LENS_TUTORIAL.adoc` walkthrough exactly.

== Intent

Every other example under `examples/tracker-lens/` is a project written by hand to demonstrate one
feature of the DSL. This one demonstrates the opposite path: running one task,
`bootstrapTrackerLensProject`, against an empty project and getting a working, two-project setup
back — the lens CSS, the Gradle project to publish it, and a project to test it against — with
nothing hand-written at all. `generated/` is exactly what that task wrote, unedited except for
adding a Gradle wrapper to each of its two subprojects so they're runnable here the same way every
other example in this repository is.

== The Generated Files

.`generated/README.adoc`
[source,asciidoc]
----
= Tracker Lens bootstrap project

Generated by `bootstrapTrackerLensProject`. Two independent Gradle projects, matching the
tracker-lens plugin's own `LENS_TUTORIAL.adoc` walkthrough:
...
----

`generated/lens-pack/` is a minimal `java-library` + `maven-publish` project whose only resource is
`src/main/resources/META-INF/arc-e-tect/tracker-lens/lenses/my-lens.css` — byte-identical to what
`initTrackerLens` alone would have written.

`generated/sample-project/` applies `tracker-lens`, registers one `bdd-scenarios` tracker against a
small bundled `gherkin-progress-history.ndjson`, and declares `lensStyle 'com.example:my-tracker-lens-pack:0.1.0'`
against `../lens-pack`. Its `tracker-lens` plugin version is pinned to `0.3.1` — the version that
was actually applied when this example was generated.

== Build And Run

[source,bash]
----
cd examples/tracker-lens/scaffolded-lens-pack/generated/lens-pack
./gradlew publish

cd ../sample-project
./gradlew generateTrackerLensDashboard
----

== What To Expect

Both builds are expected to pass. `lens-pack`'s build publishes to `lens-pack/build/localMaven`;
`sample-project`'s build writes `sample-project/build/reports/tracker-lens/dashboard.html`, whose
lens switcher includes `my-lens` alongside the three built-ins — exactly as `LENS_TUTORIAL.adoc`
describes.

= Mirage API Detector — With Mirage APIs Example
:toc: left

== Description

This example applies the Mirage API Detector plugin to an `InvoiceController` that has drifted out of sync
with its OpenAPI document: the document describes a `DELETE /invoices/{id}` operation - written ahead of the
implementation - that was never actually built. `failOnMirage` is enabled, so the build fails once the
mismatch is detected.

== Intent

This example is intended to show what a failing mirage-API detection run looks like, and that the AsciiDoc
report is still written even though the build fails - so the mismatch is always visible, not just reported
as a bare failure.

This is the plugin's canonical "why this exists" example: an endpoint that is documented and reviewed but
never implemented is exactly what `mirageApiDetector` is meant to catch before a consumer discovers it the
hard way.

== The Controller And Document

[source,java]
----
@RestController
@RequestMapping("/invoices")
public class InvoiceController {

    @GetMapping
    public String listInvoices() { ... }

    @GetMapping("/{id}")
    public String getInvoice(@PathVariable Long id) { ... }

    @PostMapping
    public String createInvoice(@RequestBody String invoice) { ... }

    // No deleteInvoice()/cancelInvoice() handler exists.
}
----

Full source: `src/main/java/com/arc_e_tect/example/invoicing/InvoiceController.java`.
The OpenAPI document - `src/main/resources/openapi/openapi.yaml` - describes `GET /invoices`,
`POST /invoices`, `GET /invoices/{id}`, *and* `DELETE /invoices/{id}` (`cancelInvoice`), which has no
matching handler.

== Build And Run

[source,bash]
----
cd examples/mirage-api-detector/with-mirage-apis
./gradlew detectMirageApis
----

`./gradlew build` fails the same way: this example wires `detectMirageApis` into the `check` lifecycle task
explicitly in `build.gradle`, since the plugin does not do so automatically.

== What To Expect

The build is expected to fail:

[source]
----
> Task :detectMirageApis FAILED
mirageApiDetector: found 1 mirage API(s) described in the OpenAPI documentation but not implemented by any @RestController class. See .../mirage-apis.adoc
----

`build/reports/mirage-api-detector/mirage-apis.adoc` is still written before the failure. It opens with a
preamble explaining what a mirage API is (see link:../../../mirage-api-detector/README.adoc[the plugin
README]'s "Report output" section), then lists the unimplemented operation:

[source,asciidoc]
----
== Mirage APIs

=== Invoices

[cols="1,3,3,3",options="header"]
|===
| HTTP Verb | Path | Operation ID | Tags

| DELETE
| /invoices/{id}
| cancelInvoice
| Invoices
|===
----

== Suggested Fix

Either implement a `deleteInvoice`/`cancelInvoice` handler in `InvoiceController` for `DELETE
/invoices/{id}`, or remove the operation from the OpenAPI document if it was never meant to ship.

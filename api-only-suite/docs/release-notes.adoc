== 3.12.1 replaces 3.12.0

3.12.0 was meant to carry the three detectors released with it: shadow-api-detector 3.8.0, mirage-api-detector 4.9.0 and doppelganger-api-detector 2.11.0.
It carries shadow-api-detector 3.7.2 instead, because its release did not wait for Shadow's release run of the same commit (link:https://github.com/Arc-E-Tect/SoftwareEngineeringDoneRight-Gradle/issues/302[issue #302 ↗]).
With 3.12.0, a controller that implements an interface generated from the OpenAPI contract has its endpoints found by Mirage and Doppelganger, but not by Shadow.

3.12.1 carries all three, shadow-api-detector 3.8.0 included.
Use 3.12.1 rather than 3.12.0.
